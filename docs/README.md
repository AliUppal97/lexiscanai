# LexiScan AI Documentation

Welcome to the official documentation hub for LexiScan AI, an enterprise-grade AI-powered document processing platform.

Use the left navigation to explore topics. Start with Quick Start or Architecture if you’re new.

## What is LexiScan AI?
LexiScan AI ingests PDFs and office documents, analyzes them with AI, and provides search, review, and reporting features for legal, compliance, and enterprise teams.
