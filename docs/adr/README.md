# Architecture Decision Records (ADRs)

ADRs capture significant architectural decisions, their context, and consequences.

## Process
1. Propose: Create a new ADR using the template.
2. Review: Discuss via PR; gather approvals.
3. Decide: Merge ADR with status Accepted/Replaced/Superseded.

## Index
- 0001: Record architecture decisions

## Status keys
- Proposed, Accepted, Rejected, Superseded
